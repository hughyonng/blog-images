<p>我原本是看到一个博主的视频，利用github、cloudflare、telegram、离线翻译模型等免费资源做了一个agent，所以就想试试。</p><p></p><p>利用claudecode和deepseek的v4flash作为编程助手，最终做出一款集聊天、评论、搜索和PDF文档翻译功能为一体的初代agent openwolf。</p><p></p><p>我个人更看重这个agent的PDF翻译功能，毕竟文档一扔，整本的翻译就出来了，简直了。</p><p></p><p>目前只是初代，继续优化，但是这个ai开发助手怎么说呢，确实没有GPT、gemini等好用，无语，但胜在便宜吧，</p><p>以下是让这个助手自己写的开发感悟。</p><p></p><p>我们最开始想要的其实很简单：一个能翻译 PDF 的 Telegram Bot。</p><p></p><p>那时候的架构天真得可爱——GitHub Actions 触发，Issue 评论当 API 用，每次翻译请求要等五分钟让 GitHub 的虚拟机慢吞吞地启动、拉代码、装依赖、跑脚本，然后把结果贴回 Issue，再推送到 Telegram。</p><p></p><p>能用，但每一步都像是在泥里走路。</p><p></p><p>人都说「能用就行」，但我们都知道这不叫能用，这叫将就。</p><p></p><p>第一刀砍的是 GitHub Actions。我们拉了一个 Cloudflare Worker 做 bridge，专职收 Telegram 的 webhook。后来又拉了第二个 Worker 做 consumer 从队列里取消息。又拉了一个 H​F Spaces 专门跑翻译模型。</p><p></p><p>一个按钮的 Bot 背后，成了一座三个组件搭起来的微缩王国。</p><p></p><p>但麻烦才刚刚开始。</p><p></p><p>Consumer 部署上去，日志什么也不打印。消息进了队列，凭空消失了。我盯着 Cloudflare 的日志面板看了整整一天——没有错误，没有崩溃，什么也没有。后来才发现是 <code>await import()</code> 在 Workers 里会静默崩溃，dispatch 锁的 ack/retry 逻辑写得也有问题。</p><p></p><p>改了。</p><p></p><p>改了之后又开始 524 超时。Spaces 翻译一个章节要两分钟，Cloudflare 只给 180 秒。我们造了一个轮询方案——Consumer 调 Spaces 的异步接口，拿到 task_id 就每十秒来问一次，好了就拿走。这回不超时了。</p><p></p><p>但文件又传不过去了。</p><p></p><p>本来文件走 GitHub：Bridge 上传，Consumer 传路径，Spaces 下载。我想着绕开 GitHub 能更快，改成 fileId 直传。结果就是一场噩梦。Spaces 收不到，Consumer 不认，Bridge 发了等于没发。调了一整天，最后灰溜溜地回退了。有些路看起来短，走起来才知道为什么别人不走。</p><p></p><p>那天晚上我跟用户说：回退吧，稳定大于一切。</p><p></p><p>他说好。</p><p></p><p>回头看看，这大概是这次重构里最大的收获——知道什么时候该停。</p><p></p><p>不止一次的深夜，我对着重复的报错消息发呆。「这回肯定能行」说了一遍又一遍。但每次都不行。数据对不上就修数据，修完发现逻辑不对，逻辑改完发现接口变了，接口对齐后发现最初的假设就是错的。一圈绕回来，代码已经千疮百孔，用户也等得没脾气了。</p><p></p><p>后来我学会了一件事：不管功能多诱人，先把能跑的稳住。翻译能跑就不动翻译，搜索能搜就不改搜索。要加什么功能之前，先问问自己——是不是非改不可？是不是非现在改不可？</p><p></p><p>这个道理本来很简单。但人总是在疼过之后才记得住。</p><p></p><p>现在这个 Agent 是这样的：</p><p></p><p>你发一个 PDF 给 Telegram Bot，它收下文件，上传到 GitHub，往队列里塞一条消息，Consumer 取走消息去问 Spaces。Spaces 那边，翻译模型加载了一分半钟，然后把你的 PDF 逐段译成中文。Consumer 每隔十秒来检查一次，拿到结果就推到你手机上。</p><p></p><p>整个过程三到五分钟。不算快，但每一步都走得稳。万一哪步断了，重试三次之后自动认栽，从不卡死。</p><p></p><p>这就够了。用户要的不是完美，是可靠。</p><p></p><p>明天还要搞 R2 存储，把 GitHub 换掉，支持大文件。然后修搜索。然后把那些改了又改、修了又坏的小毛病一个个收拾干净。</p><p></p><p>但那是明天的事了。</p><p></p><p>今天，翻译是通的。这就很好。</p>
